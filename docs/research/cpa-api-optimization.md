# CPA API 优化实现

适用范围：V2 rc.20 的优化实施记录。当前使用入口见 [文档导航](../README.md)。

[v0.2.0-rc.20](../releases/v0.2.0-rc.20.md) 基于 [2026-10-29 API 分析](cpa-api-review-2026-10-29.md) 优化 V2 后台、原生桥和面板，后台与接入层均为 rc.20；数据库继续使用 schema 9，无新增迁移。

## 额度查询与代理

未指定账号代理时，额度查询通过 `host.http.operation_open` / `host.http.do` / `host.http.cancel` 继承 CPA 全局 HTTP 代理。账号显式指定 direct/none 或 HTTP(S)/SOCKS 代理时继续使用独立连接池，不继承系统环境代理。

桥接仅允许 GET 固定的 wham/usage 地址及四个查询请求头。HTTP 操作与创建它的桥接实例绑定，后台握手发现替换实例时也不会把旧操作重放过去。最多保留 8 个操作，正常返回也显式释放；超时、后台断开或退出时由取消和回收逻辑清理。额外保留取消调用位置，8 路请求阻塞时仍能取消。

查询前后的账号身份核对、临时 token 使用和响应归一化继续保留。未具备宿主 HTTP 回调的旧桥接层会明确失败，不静默改为直连；部署必须同步更新桥接层和后台。

2 MiB 限制约束后台接受的响应。CPA 当前 `host.http.do` 会先读取完整上游响应，因此此限制不代表宿主峰值分配上限；宿主请求也遵循 CPA 自己的重定向策略。账号专用 transport 继续禁止重定向。严格限制宿主的上游读取需要后续流式 HTTP 回调或上游能力支持。

## 按账号模型目录

新增 `GET /v0/management/codex-window-refresh/v2/account-models?account_id=...`。后台列举账号并在 `host.auth.models` 前后核对 ID、索引、provider 和桥接实例，只返回模型 ID，不读取认证 JSON。

回调结果限制为 512 KiB、2048 个模型，每个模型 ID 最长 200 字节。面板优先使用此入口；只有旧入口缺失或宿主明确返回不支持时才回退旧管理读取，身份变化、网络异常和错误响应不会引发回退。

模型目录用于填写建议。已注册不代表实时权限或额度，发送前仍执行现有准入流程；本次未增加“必须出现在目录中”的发送限制，继续兼容手动模型名。

单个已确认启停账号的周期读取使用 `auth_index` 过滤；多个账号仍合并读取。启停修改前后保留完整的唯一性核对。

## 同步与流式观察

每 30 秒完整读取并核对账号身份的逻辑继续保留。数据库改为暂存后批量合并：只更新变化账号，每轮推进一个统一心跳，绑定确认检查点合并到 5 分钟。状态时间与旧查询结果校验共同使用心跳，避免减少写入后出现状态回退。

100/1000 账号的本地数据库模拟基准如下，基准包含写入审计触发器。数字不包含宿主回调与网络，不代表生产总耗时。

| 未变化账号数 | 原同步耗时 | 优化后耗时 | 原分配 / 新分配 | 常规持久行更新 |
| --- | --- | --- | --- | --- |
| 100 | 6.53–6.69 ms | 2.25–3.78 ms | 212 / 32.7 KB | 201 → 1 |
| 1000 | 46.8–49.6 ms | 4.09–4.61 ms | 2110 / 306 KB | 2001 → 1 |

绑定检查点到期时会额外更新绑定行。可运行 `go test ./internal/v2/store -run '^$' -bench BenchmarkSyncUnchangedInventory -benchmem` 重测当前版本。

原生 SSE 观察现在在解码元数据前检查 ChunkIndex，普通正文 chunk 不再分配身份和账号字符串。宿主逐 chunk 的 RPC 及正文封装仍存在，更大的优化需要 CPA 提供只观察响应头的接口。HTTP、SSE 初始化和 WebSocket 的被动额度覆盖保持原有语义。

## 构建与验证

运行 `make v2-build` 生成 `bin/window-refreshd` 和 `bin/codex-window-refresh-v2-bridge.so`。rc.20 桥接二进制和路由已变化，现有部署需要按[安装流程](../user/install.md)同时更新两者并显式使用 `--restart` 重启 CPA，不能只替换后台。

验证结果：`make check` 全量 Go 测试及 vet 通过；`make v2-smoke` 的 42 项原生假宿主测试和 246 项 Node 测试通过；`go test -race ./internal/v2/...` 通过。新增覆盖包含固定额度地址、操作所有权、8 路阻塞取消、超时及退出回收、模型目录身份变化与旧宿主兼容、同步写入量和状态时序。

未使用真实账号做额度或模型请求，也未进行真实 CPA v8.0.47 的生产联调。
