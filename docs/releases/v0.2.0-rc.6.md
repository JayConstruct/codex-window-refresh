# v0.2.0-rc.6 可折叠侧栏、模型配置与手动候选生成

- 左侧导航支持折叠和展开，桌面保留图标导航，手机可收起菜单；按 CPA 路径隔离记住浏览器偏好，不保存管理密钥。
- 运行总览的五小时、周到期查询开关可原地直接保存，不再跳转。仅保存点击的开关，不夹带编辑器其他草稿；保存中锁定，失败恢复最后已知状态，冲突或结果未知时须明确重新读取核实。
- 模型与提示词页面接入真实持久配置：默认模型、默认提示词、五小时与周规则独立覆盖，以及固定/随机短句策略。支持差异预览、草稿保留、版本冲突保护和重启恢复；模型名称手动填写实际可用值，不伪造可用模型目录。
- 短句池支持编辑、纯文本导入导出、确认去重和清空，以及不消耗额度的本地随机预览。生成结果经选择后仅加入草稿，显式保存才写入配置。
- 接通显式手动候选生成：填写可用 Codex 账号、模型和数量（1–20），确认会消耗额度后才提交。请求固定到该账号，不回退其他账号；额度查询、页面刷新、同步及配置保存均不触发模型请求。
- 候选生成采用持久任务、幂等标识及独立串行 worker。网络写入未确认时只可显式核实原请求；已执行但未确认完成的任务在后台重启后标记结果未知，不自动重发。结果未知可能已计费，不应换新标识重复生成。
- 原生接入层仅新增有界的模型流打开、读取和关闭方法，校验协议、指定账号和模型，限制流数量与数据大小，关闭失败保留所有权，避免错误释放后卸载仍在运行的回调。

自动唤醒、实时唤醒执行及每日容量准备仍未接入；保存模型配置不代表自动唤醒已启用。`model_execution=false` 是原有自动执行能力标记，显式手动候选生成单独由 `prompt_generation` 标识；不要据旧标记断言不会产生任何模型请求。

## 升级与测试

本版须同时更新后台和接入层，并显式 `--restart` 重启 CPA，会短暂中断服务。现有 V2 数据和查询设置保留，数据库迁移到 schema 5；建议另行保留一致备份，降级不能只替换旧二进制。自动安装器支持 Debian 12/13 和系统级/用户级 systemd 服务。

```sh
curl -fSL https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.6 --restart
```

更新完成后强制刷新网页，先检查侧栏、总览开关和模型配置保存，再选择测试账号验证手动生成。候选生成会实际消耗模型额度；不测试生成时不要勾选并提交消耗确认。

本地已通过 83 项前端测试、21 项原生桥接测试、完整 Go 测试、V2 竞态检查和桌面/移动端浏览器回归。模型流及故障恢复使用模拟宿主验证，没有使用真实账号执行模型请求，不声称已完成真实账号生成联调。
