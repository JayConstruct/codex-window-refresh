# v0.2.0-rc.22 修复调度页面 404，并复用额度查询的重置卡数量

修复 rc.21 原生桥管理路由已注册但未加入转发白名单的问题。账号调度设置的读取、保存和重置卡列表现在可正常经过 CPA 原生桥访问，打开页面不再因此显示“记录不存在，已显示的数据可能已过期”。

账号额度查询现在保留官方 `/wham/usage` 响应中可选的 `rate_limit_reset_credits.available_count`，同步显示重置卡数量，不增加网络请求，也不需要安装 Codex CLI。缺失或无效字段保持未知；查询乱序、部分响应和账号替换不会覆盖较新的有效观测。

卡片 ID 和到期时间仍通过独立详情查询取得，需要支持账号协议的 Codex CLI。数量变化时隐藏不再匹配的旧详情，更新数量不会刷新旧详情的观测时间；未知到期时间不自动兑换。

后台与原生桥均更新至 rc.22，升级必须显式 `--restart`。数据库保持 schema 10，保留 rc.21 设置、额度和兑换防重记录；从 rc.20 或更早版本升级仍需先保存一致备份并迁移到 schema 10。使用方法见[账号调度与重置卡说明](../user/account-scheduling.md)。

验证覆盖经过原生桥的真实后台 GET/POST、配置冲突及重启持久化，以及额度查询到重置卡列表的完整读取链路；Chromium 检查新增调度页面导航和移动布局。仅使用模拟账号，未兑换真实重置卡。
