# v0.2.0-rc.11 统一操作提示与更新脚本修复

## 网页操作提示

- 查询与同步提交、查询及唤醒规则保存、模型配置、模型目录读取、短句导入导出和候选/唤醒结果统一使用右上角全局 toast；跨页仍可查看，不再在多个卡片重复提示。
- 成功提示约 4.5 秒关闭，普通提示约 6 秒关闭；悬停或键盘焦点位于提示内时暂停关闭。错误和结果未知等警告不自动关闭，支持手动收起。关闭提示不会解除任务发送保护或创建模型请求。
- 同一通道复用提示，相同轮询结果不重复弹出或延长计时。正常后台读取和输入草稿保持安静，不覆盖保存回执；模型目录读取不覆盖结果未知的任务警告。
- 提示不抢输入焦点，适配桌面和手机，使用纯文本及辅助技术状态/警报语义。字段校验、草稿差异、功能说明、额度消耗确认和持续任务状态继续保留原位。

## 一键更新

- 独立下载的 V2 Shell 入口重新获取两份 Python 安装器，不复用下载目录中残留的旧副本；下载失败立即停止，不运行旧安装器。完整源码目录仍使用本地脚本，离线安装仍使用包内 Python 入口。
- V1 入口明确提示仅更新 V1；不静默切换到 V2。安装器输出已选择、当前及实际后台版本和独立接入层版本，避免把 CPA 插件列表的接入层版本误认为后台版本。
- 脚本和发布列表查询请求携带重新验证缓存的请求头。V2 的 latest 继续按数值比较已发布 rc 版本，不依赖 GitHub Latest 标记或列表顺序；最新发布包未完整上传时停止，不静默安装旧版本。

## 升级

后台为 `0.2.0-rc.11`，数据库仍为 schema 8，原生接入层仍为 `0.2.0-rc.8`、ABI 1/schema 6。CPA 插件列表仍可能显示 rc.8；请以安装器核实的实际后台版本或网页诊断中的后台版本判断更新结果。

升级前另存一致备份。更新到本版：

```sh
curl -fSL -H 'Cache-Control: no-cache' https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.11
```

如果安装器提示接入层变化，确认允许 CPA 短暂中断后添加 `--restart`；首次切换、旧接入层或接入层文件变化仍须显式重启，不会自动重启未知进程。用户级服务继续支持 `--user-service --user 用户名 --service 服务名`，保留实际部署所需参数。以后使用 `--version latest` 更新最新已发布 V2。

升级保留现有 V2 查询/唤醒规则、模型、提示词、短句池及任务防重记录，不自动开启或关闭既有规则，不调用真实账号模型进行安装验收。已明确开启的自动规则继续独立执行。更新后强制刷新网页加载新资源。
