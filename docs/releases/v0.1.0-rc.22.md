# v0.1.0-rc.22 测试版

一键安装 / 更新脚本默认使用热重载，无需再加 `--hot-reload`，不重启 CPA，也不需要管理 key。

## 变化

- `scripts/install.sh` 和委托它的旧升级入口默认传入 `--hot-reload`，继续通过本机版本文件及本次配置标记确认实际接管。
- 显式 `--restart` 选择普通安装并重启已核实的服务；首次安装、rc.20 及更早版本或缺少版本文件时使用。热重载失败不会自动改为重启，也不会自动改用普通安装。
- `--no-restart` 选择普通安装但不重启，不执行热重载确认。三种生效方式互斥，冲突在下载或安装依赖前拒绝，避免参数顺序影响是否重启。
- `--dry-run` 预览默认热重载，不下载或修改部署文件；模型诊断和卸载不会继承默认热重载。卸载仍只有显式 `--restart` 才重启。
- 当前运行版本与目标版本相同且插件文件校验一致时，直接提示无需更新，不修改部署文件或重启。相同版本但文件不一致时拒绝覆盖，降级仍要求显式普通安装并重启。

## 使用

已安装 rc.21 或更新版插件时，直接执行：

```sh
curl -fSL https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install.sh -o /tmp/codex-window-refresh-install.sh && sudo bash /tmp/codex-window-refresh-install.sh
```

首次安装或旧版没有 `runtime-version.json` 时，在命令末尾加 `--restart`；之后继续使用不带此参数的命令即可。沿用原来的路径、用户、服务及查询方式参数。版本文件由插件自动生成，无需手动创建。

直接调用 Python 安装器时，保留原来的显式激活方式：热重载使用 `--hot-reload`，重启使用 `--restart`。详细参数见 [安装说明](../install.md)。
