# v0.2.0-rc.3 正常业务额度观测

独立后台现在可以保存正常业务响应中的额度证据，不需要为这些观测发起额外的额度 HTTP 请求。

- 接入 HTTP 响应头、流式响应头初始化及 Codex WebSocket `codex.rate_limits`/带额度头的 `error` 事件。普通流式内容块不重复刷新额度时间。
- 原生钩子只提取允许字段，返回空修改结果，保留原响应内容和响应头。正文、普通流内容、认证头和 WebSocket 错误正文不进入事件或数据库。
- 独立工作池同步 CPA 本地账号及绑定摘要，不依赖先点击查询；凭据只在宿主适配器中短暂读取，不写入数据库。绑定变更后清除旧证据，拒绝旧请求响应。
- 按权限、五小时和周窗口分别保存来源、观测时间及读取开始时间。较早发出的慢查询不能覆盖较新的业务观测，部分事件不会刷新缺失字段。
- 原生工作池保留 8 个真实宿主调用槽，另留控制处理能力；全部宿主调用阻塞时，握手、事件拉取及 ACK 仍可处理。客户端超时不释放仍在宿主执行的物理槽。
- schema 1/2 迁移到 3，保留 v2 任务和幂等记录。沿用部署成功后清理 v1 数据及旧版本的行为。

本次接入层也有变化，更新须使用 `scripts/install-v2.sh --restart`。只读范围保持不变，模型与自动规则尚未开启。账号摘要每 30 秒同步，原生绑定视图 90 秒过期；它不是宿主权威凭据代际，无法证明识别所有同 ID 重新登录或重试交错。缺失、过期或无法核实的绑定不接受额度。真实 CPA 的认证转发、实际业务各路径仍需实机验收；自动化测试均使用无真实凭据的假宿主。
