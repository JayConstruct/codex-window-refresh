# v0.2.0-rc.7 反重力短句生成与独立账号目录

- 短句池的手动模型候选生成支持 CPA 的 Codex 和反重力（`antigravity`）账号；生成页可选择账号，显示提供方和可用状态，并显式刷新本地账号目录。
- 填写所选提供方实际可用的模型、数量（1–20），确认可能消耗额度后才发送。不会按模型名称猜测提供方，也不会在失败后更换账号或提供方重发。生成候选仍需勾选加入短句池草稿，再显式保存配置。
- 生成账号目录与 Codex 额度库存独立。反重力账号不计入 Codex 账号总数、容量、额度查询队列或自动查询；读取目录、查看页面及保存配置不发送模型请求。
- 提交与执行前核验指定账号、提供方、索引及身份摘要；重复身份、禁用、移除或替换均拒绝。反重力邮箱、项目 ID 和 token 不进入目录、任务响应或数据库，OAuth token 刷新不改变身份摘要。
- 接入层声明支持的生成提供方并严格限制协议配对；旧接入层仅按支持 Codex 处理。跨提供方选择清空已填模型并撤销消耗确认；账号目录刷新不自动换账号、不解除结果未知保护。
- 延续持久任务和幂等保护：同一标识返回原任务，即使账号或宿主已不可用也不创建新请求；执行结果未知、流错误或重启中断不自动重发，不回退到其他账号。

自动唤醒、实时唤醒执行和每日容量准备仍未接入；仅保存模型配置不会启用自动模型请求。

## 升级与测试

本版须同时更新后台和原生接入层，并显式 `--restart` 重启 CPA，会短暂中断服务。数据库迁移到 schema 6，保留现有 V2 配置、任务、结果和幂等记录；schema 5 的旧生成任务按 Codex 保留，已开始但未确认完成的任务不会因升级重发。升级前请另行保存一致备份，降级须停服务并恢复备份，不能只替换旧二进制。

```sh
curl -fSL https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.7 --restart
```

用户级 systemd 服务继续支持 `--user-service --user 用户名 --service 服务名`。更新后强制刷新网页，在“模型与提示词”中刷新生成账号、选择账号及实际模型，再按需确认生成；真实生成会消耗所选账号模型额度。

本地通过完整 Go 测试、V2 竞态检查、vet、97 项前端检查、25 项原生桥接测试、115 项安装脚本测试及桌面/移动端 Chromium 验证。模型协议、幂等恢复、账号隔离及故障路径使用模拟宿主验证，未调用真实账号模型，不声称已完成真实 CPA 账号生成联调。
