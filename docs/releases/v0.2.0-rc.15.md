# v0.2.0-rc.15 账号启停、显示隐私与唤醒诊断

## 功能

- 主页面账号行新增 CPA 启用/禁用开关。按真实账号 ID、认证文件名和索引核对独立 Codex 认证文件，确认后只提交一次状态修改，再读取 CPA 目录核实。启用可能恢复业务及已授权自动任务的额度消耗；开关操作本身不发送模型，不解除未知任务防重。
- 请求超时、断开或 HTTP 错误不等于修改未发生；结果不确定时仅允许只读核实原目标，不自动重发。运行时账号、虚拟子账号、配置密钥、身份不唯一及变化的文件拒绝修改，不上传或替换认证文件。
- 页面账号支持原始、打码和本地别称显示。偏好按浏览器、CPA 地址及路径隔离；全页账号文字和辅助标题同步处理，长别称单行省略。别称不改变实际账号、任务或模型请求身份，不代表服务器数据匿名化。
- 唤醒原因区分账号未找到、已禁用、CPA 暂不可用、清单未同步或过期、身份不唯一、绑定缺失及绑定变化。旧通用错误不猜测具体原因；发送后结果未知仍保留防重，只更新核实原因。
- 新旧唤醒任务的 `skipped` 均按正常跳过展示，不计入异常数量，不显示错误卡片；保留跳过原因及记录。真正失败和结果未知仍需关注。

功能边界和官方 CPA 接口依据见 [账号开关与显示偏好](../backend-v2-account-controls.md)。

## 升级

后台版本为 **0.2.0-rc.15**，原生接入层沿用 **0.2.0-rc.14**。数据库仍为 **schema 9**，ABI 1、RPC schema 6、协议版本 1 不变。从 rc.14 更新且安装器核实接入层文件完全一致时可仅更新后台；从 rc.13 及更早版本更新、首次安装或接入层文件变化须显式 `--restart`。保留实际部署所需的 CPA 路径及系统/用户服务参数。

升级前另存停机或 SQLite 在线一致备份；不清除发送防重记录，不只复制活动 WAL 数据库主文件。升级不自动开启规则，不创建额度查询或模型测试。打码/别称为浏览器本地偏好，不随安装包部署到其他浏览器。

确认 CPA 可短暂重启后，可执行以下通用更新命令：

```sh
curl -fSL -H 'Cache-Control: no-cache' https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.15 --restart
```

以后可使用 `--version latest`。一键脚本仍按版本号选择最新已发布 V2（包括 rc），不依赖 Latest 标记。更新后强制刷新网页。
