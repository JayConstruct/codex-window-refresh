# v0.2.0-rc.1 独立后台只读预发布

首次发布 v2：C ABI 接入层兼容现有 CPA ABI 1/schema 6，独立 Go 后台承载网页、查询任务、并发、活动观测和 SQLite。无需修改 CPA 宿主源码。

- 额度查询采用可配置工作池，同账号合并在途查询；任务、结果和幂等键跨后台重启保留。
- 生命周期事件按序号重放，事务提交后确认；溢出与接入层重载明确标记缺口和未知占用。
- 页面校验后台实例与视图版本，分页变化时重新读取；历史裁剪后保留独立幂等回执。
- 单独提供 amd64/arm64 Debian 12/13 包及 `scripts/install-v2.sh`。首次切换须显式 `--restart`，以后仅后台变化时不重启 CPA；接入层变化仍要求显式重启。
- 安装器校验 SHA-256、架构、协议和 glibc，备份配置及 SQLite，并核对后台版本、接入实例和目标 CPA PID。激活失败则停止新进程后恢复文件与数据库备份。

这是只读预发布：不执行唤醒、短句生成或自动规则，不导入 v1 业务状态。首次切换会停止 v1 功能；原策略与状态保留。普通 v1 更新不会自动切换到此包。安装与回退方法见 [v2 安装说明](../backend-v2-install.md)。

验证使用无真实凭据的模拟 CPA；实际 CPA 注册、认证转发、代理和真实上游仍需实机验收。CPA 不提供权威的初始在途快照，因此活动统计只表示已观测范围，不作为完整占用量。
