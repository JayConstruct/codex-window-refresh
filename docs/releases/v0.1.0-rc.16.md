# v0.1.0-rc.16 测试版

完善面板的设置保存、账号查看与任务追踪，并优化已绑定账号的单账号额度查询链路。

## 本次变化

- 浏览器记住“自动刷新页面”和“后台标签页继续刷新”，重新打开或连接成功后恢复。首次默认关闭，断开和认证失效仍停止读取；不保存手动密钥，不修改 CPA 登录状态。关闭自动刷新同时关闭后台刷新。
- 总览使用紧凑运行状态条，刷新设置、运行说明和额度来源说明可折叠。区分页面读取时间与额度观测时间；查询失败保留旧值并提示，不把页面刷新误报为新额度。
- 账号支持按名称、五小时或周剩余比例、五小时重置时间及异常状态排序，新增桌面紧凑列表；手机保留卡片。排序和布局记在当前浏览器，不写入服务器策略。
- 账号刷新复用卡片和按钮，保留可用控件焦点、展开状态与选中文字；操作中暂缓自动重排，显式切换排序立即生效。暂停按钮始终读取最新草稿，禁用与账号移除仍及时生效。
- 保存前显示具体配置差异。字段旁校验数值、时段、延迟、模型、短句池和每日规则；点击保存可定位首个错误，无效输入和未保存草稿保留。应用生成短句不会覆盖其他未完成输入，服务器继续执行最终校验。
- “计划与历史”拆分未来预览与执行历史，增加今天、最近 7 天、仅失败、清空筛选、上一页和下一页；可从账号直接进入其历史。日期快捷项按浏览器日历计算，记录时间按规则时区显示；历史读取失败保留上次结果，不新增上游查询或模型请求。
- 已绑定账号的单账号查询重新核对目标账号的身份和凭据代际，避免每次遍历整个账号池；首次、批量、未知账号及不支持目标读取的宿主仍执行完整发现。后台普通观测和模型预检在调用间让行手动查询，已发出的请求不会因提速而取消重发。
- 显式账号代理复用隔离且有界的连接池，每次查询仍重新读取 token；插件退出后释放连接。手动额度任务新增排队、身份读取、额度查询、落盘及总耗时统计，不包含浏览器轮询与渲染；真实耗时取决于宿主、代理和上游。

## 安装或升级

已有 CPA 的 Debian 12/13 服务器可指定版本升级：

```sh
curl -fSL https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install.sh -o /tmp/codex-window-refresh-install.sh && sudo bash /tmp/codex-window-refresh-install.sh --version v0.1.0-rc.16
```

升级保留已有策略、模型及窗口状态；安装器默认重启已核实的 CPA systemd 服务，可能短暂中断请求。使用 `--no-restart` 可稍后手动重启。路径或服务不明确时沿用 `--cpa-dir`、`--service`、`--user-service`、`--user` 等参数；Docker 按安装指南替换插件。

替换插件并重启 CPA 后刷新管理网页。旧版首次升级不会自动开启页面刷新；勾选后才在当前浏览器记忆。定期额度查询、到期查询和模型唤醒继续通过“保存并应用”生效。无需清空状态或迁移历史。

## 验证与边界

发布流程要求 Linux amd64、arm64 各自通过 Go 测试、竞态检测、vet、配置检查器构建、原生 ABI 加载、安装器与发布一致性检查，以及 Chromium 浏览器回归后，才发布两种安装包和 SHA256SUMS。前端逻辑测试共 92 项，覆盖偏好、排序、配置差异、输入校验、历史快捷日期与分页、原有快照与任务安全；浏览器使用本机模拟服务验证焦点、文字选择、排序稳定、历史入口、配置冲突与移动布局。

仍要求 CPA ABI 1 / RPC schema 6；尚未连接真实 CPA 宿主或生产账号验证。浏览器偏好不跨设备同步，存储不可用时仅保留当前会话；浏览器冻结、后台节流及电脑休眠期间不保证持续刷新。账号移除或按钮因后台状态变化不可用时，相关内容或焦点可能变化。后台查询、自动唤醒与未知送达抑制规则不因页面优化而放宽。
