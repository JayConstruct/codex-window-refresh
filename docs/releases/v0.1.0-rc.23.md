# v0.1.0-rc.23 测试版

查询账号额度时同步更新 CPA 账号状态，无需等待下一轮约 30 秒的后台清单刷新。

## 变化

- 单账号、批量和自动额度查询复用查询前后的 CPA 绑定核验结果，同步账号禁用、暂不可用及恢复状态，包括查询过程中发生的变化。
- 账号状态以 CPA 返回为准；额度查询成功不会解除 CPA 限制，CPA 确认恢复时才更新为可用。已保存的账号暂停继续有效。
- 额度查询失败时仍同步成功核实的 CPA 状态，并保留原额度及观测时间；本地状态读取失败时不推断恢复。凭据代际变化时清除旧证据，拒绝旧请求返回的额度。
- 只更新所查账号，不因同步状态额外扫描整个账号池或发送模型请求。额度和状态随同一次状态提交发布，提交失败不会显示未经保存的更新。
- 页面沿用查询任务的结果跟踪，不增加占用卡片布局的说明。安装脚本继续默认热重载，不重启 CPA。

## 升级

已安装 rc.21 或更新版时，使用原一键更新命令即可热重载。首次安装或 rc.20 及更早版本仍需显式 `--restart`；详见 [安装说明](../legacy/v1/install.md#热重载升级)。已有策略、窗口及发送抑制状态保留。

## 验证

集成回归覆盖单账号、批量及自动查询，查询期间禁用、暂不可用、恢复、上游失败、本地状态读取失败、凭据更换、账号暂停、其他账号状态保留，以及提交失败不发布。发布检查包含 Go、竞态、原生加载与热重载、安装器、前端、Chromium 和双架构构建。尚未在真实 CPA 宿主或生产账号上联调。
