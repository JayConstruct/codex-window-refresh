# v0.2.0-rc.9 编辑稳定性、账号模型目录与状态更新

- 修复模型、提示词及唤醒规则编辑时轮询短暂禁用表单，导致输入框闪烁、失焦的问题。后台仍自动更新，相同值不重复写入输入框；保留焦点、光标和草稿，首次加载、显式重新读取和保存仍使用必要锁定及版本冲突保护。
- 支持指定 Codex 账号后从 CPA 读取已注册模型，供默认及五小时/周覆盖字段选择；候选生成可独立读取所选 Codex 或反重力账号的目录。不自动选择、保存或调用模型。读取使用浏览器现有内存管理密钥访问同源管理接口，前后核对账号提供方及 auth index，拒绝文件名别名碰撞、过大响应或过期请求；不保存管理密钥、不新增虚构宿主回调。注册目录不是实时模型权限或额度验证，读取失败仍可手动填写。
- 新增显式“填入 Codex 风格编程短问句”按钮，仅修改默认提示词草稿，保存后才用于唤醒，不覆盖已有配置。唤醒继续指定真实 Codex 账号，使用 Responses 输入、流式且不存储，增加简短编程助手指令及 `tool_choice: none`，不伪造官方客户端身份或会话、不提供文件访问和命令执行，不改变用户已保存的提示词文本。
- 保留上游查询返回的原始剩余秒数；五小时窗口恰好 18000 秒、周窗口恰好 604800 秒时不显示倒计时。按查询时的值判断，不因页面停留而让完整窗口占位值开始倒数；其他值继续显示重置时间。兼容旧快照中的绝对时间与观测时间，不改变额度分类、查询或唤醒准入规则。
- 账号状态继续由后台约每 30 秒同步一次，页面关闭后也运行；页面每 5 秒读取后台结果。补齐运行时状态映射，明确的禁用、错误、等待、刷新中及未知状态不再误标正常，账号身份不可核实仍优先保护；禁用及异常账号仍可显式执行原有只读额度查询，不因此允许模型发送。
- 账号状态与筛选增加“额度耗尽”“额度受限”，总览分别统计。五小时或周额度明确为数值 0% 才显示耗尽；仅许可被阻止时显示受限。显示状态独立于宿主准入状态，不改数据库中的发送许可；重启、账号重新启用或本地倒计时结束不会清空耗尽观测，须新额度证据核实恢复。同步只读取 CPA 本地状态，不额外增加上游额度轮询或模型试发，自动查询和已开启自动唤醒仍按保存的规则独立执行。

## 升级

后台版本为 `0.2.0-rc.9`，数据库仍为 schema 8，原生接入层源码、ABI 1/schema 6 及版本 `0.2.0-rc.8` 均未改变；后台与接入层版本不同是正常的独立组件版本。保留查询设置、模型与短句池、已开启规则、任务及未知发送防重记录，不自动开启或关闭已有规则。

升级前保留停机或 SQLite 在线一致备份，不能只复制活动 WAL 数据库主文件。推荐显式重启更新以兼容首次切换和旧接入层；CPA 会短暂中断服务：

```sh
curl -fSL https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.9 --restart
```

从 rc.8 更新且安装器核实接入层文件完全一致时，可省略 `--restart`，仅更新并重启后台；文件变化时必须显式重启，不绕过校验。用户级服务继续支持 `--user-service --user 用户名 --service 服务名`。V2 一键入口不变，默认选择最新完整发布的 V2；旧 `install.sh` 仍是 V1 入口。

更新后强制刷新网页，先核对模型和提示词；目录读取与预设填入不发送模型请求。自动唤醒默认关闭，但此前明确保存开启的规则继续生效，真实唤醒或候选生成可能消耗额度。模型响应完成与额度窗口验证仍分别显示，未知结果不得换新标识重复发送。

## 验证与边界

本地回归覆盖完整 Go 测试、竞态检查及 vet、159 项 V2 前端检查、32 项原生桥接测试、安装脚本及旧面板测试和桌面/移动端 Chromium。浏览器覆盖慢速轮询期间的真实焦点和选区保持、同源账号模型目录、状态从正常到禁用/耗尽再恢复及耗尽筛选；后台覆盖身份保护、只读查询、页面关闭后的同步及发送防重。

测试使用模拟 CPA、模型流及临时安装目录，未调用真实账号模型，不声称已完成生产账号联调。CPA 原生回调尚不提供账号模型目录；浏览器目录前后核对也不是宿主原子发送绑定，实际执行继续使用独立的精确账号和额度预检。
