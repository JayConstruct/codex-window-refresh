# v0.2.0-rc.16 全自动读取与无闪烁更新

## 自动读取

- 认证连接后自动读取后台结果，前台通常约每 5 秒更新，已有查询执行中约 1.5 秒；隐藏标签页降为 30 秒，返回前台、窗口重新获得焦点或网络恢复时立即补读。刷新只读取记录，后台账号同步及额度查询仍按原规则执行。
- 首次连接遇到临时网络、超时或后台服务故障时自动重试；401/403、主动断开后不通过前台事件或浏览器后退缓存重新使用保存的凭据。密钥仍只用于当前页面内存，不新增密钥持久化。
- 已确认过的 CPA 认证文件启停每轮只读核实，不让本地确认永久遮蔽其他页面的外部变更。结果未知的启停仍保留安全提示及显式只读核实入口，不自动重发 PATCH。
- 账号、任务、历史与设置读取独立处理，某一资源暂时失败或变慢不会阻止其他资源更新；并发刷新合并为一轮及至多一轮补读，不堆叠定时器。唤醒设置或本地生成账号目录首次读取失败后可自动重试 GET，不因此调用模型。

## 显示稳定

- 未变化的数据不反复写属性、替换文字或重建节点。账号、最近事件、诊断、配置差异及倒计时增量更新；打码/别称在比较前处理，不把真实账号和显示值往返写回页面。
- 任务记录后台读取不反复切换“正在读取”画面，保留筛选、输入焦点、选择范围、未保存草稿、展开的响应和错误详情。自动读取不保存草稿，不额外创建额度查询、唤醒或候选生成任务。
- 桌面任务详情按实际顶部位置和剩余视口计算最大高度，修复 1280×900 下页头换行、复制降级及操作按钮换行时底部按钮越界；移动布局不变。

## 升级

后台为 **0.2.0-rc.16**，原生接入层仍为 **0.2.0-rc.14**，数据库 **schema 9**、ABI 1、RPC schema 6、协议版本 1 不变。保留账号、任务、模型、提示词、已有规则及未知发送防重记录，不自动开启或关闭已有规则。

从 rc.14/rc.15 更新且安装器核实接入层文件完全一致时可仅重启后台；首次切换、从 rc.13 或更早版本更新，或接入层文件变化时须显式 `--restart`。升级前另存停机或 SQLite 在线一致备份，不能只复制活动 WAL 数据库主文件。

```sh
curl -fSL -H 'Cache-Control: no-cache' https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.16
```

需要重启 CPA 时在末尾添加 `--restart`，并保留实际部署所需的路径、系统/用户服务参数。以后可使用 `--version latest`。**更新后首次重新打开或强制刷新网页，以加载新版脚本；之后正常数据更新无需手动刷新。**认证过期、配置冲突和未知发送结果仍须按安全提示处理，不自动恢复认证、保存或重发模型。

## 验证范围

覆盖 Go 全量测试、vet、竞态检查、34 项原生桥接检查、225 项面板及 15 项模型目录检查、123 项安装脚本检查、99 项旧面板回归，以及真实 Chromium 桌面/手机检查。

浏览器回归使用串行独立 fixture：原有场景保持 20 次明确操作 POST、5 次明确确认 CPA PATCH 的计数；自动刷新场景只有独立准备时的一次显式 PATCH，随后验证零额外 POST/PATCH/模型流量。实测前台闲时/查询执行中节拍、真实标签页隐藏/恢复及断网恢复；相同数据的账号与历史区域无重复属性写入、元素重建或加载闪烁，焦点与详情节点保留。

全部使用本地模拟 CPA、临时数据库及模型流，不声称已完成真实 CPA 账号或生产模型联调。
