# v0.1.0-rc.6 测试版

重构管理面板，让额度查看、额度查询和模型唤醒的用途更清楚。

## 本次变化

- 页面分为“总览”“账号额度”“额度查询”“模型唤醒”“诊断与高级”。顶部持续显示当前已应用的运行模式，区分只查询额度与开启模型唤醒。
- 总览优先显示账号额度状态和手动查询进度。“更新页面数据”与“立即查询额度”分别说明读取快照和查询上游的区别。
- 自动与手动额度查询设置独立成页；模型唤醒按发送内容、所需容量、触发时间和每日目标分组。
- 账号卡片突出剩余额度、重置时间和观测来源。唤醒任务默认折叠，自动更新会保留展开状态。
- 所有页面共用草稿与底部保存栏，切换页面仍能保存或放弃更改。维护操作和 JSON 编辑器移至“诊断与高级”。
- 适配手机布局，并支持使用方向键、Home 和 End 切换标签。

## 使用和升级

更新后重启 CPA 并刷新管理中心。只查看额度时，在“模型唤醒”关闭总开关，在“额度查询”设置自动或手动查询，最后点击“保存并应用”。未保存的设置不会改变顶部显示的生效模式。

重新下载并运行安装脚本，沿用原 CPA 路径、服务和用户参数，指定 `--version v0.1.0-rc.6`。升级保留已有策略、私有管理密钥环境文件和窗口状态；提供 Linux amd64、arm64 安装包及 SHA256SUMS。

## 验证与边界

本版调整页面布局和展示，不改变额度查询接口与后台唤醒调度规则。通过前端逻辑测试、本地 Chromium 的五页面布局与交互验证、Go 检查及原生插件加载验证。发布前继续执行两种架构的构建、竞态检测和安装测试。

仍要求 CPA ABI 1 / RPC schema 6；尚未在真实 CPA 宿主或生产账号上联调。
