# v0.2.0-rc.17 直接操作与账号拨动开关

## 页面操作

- 总览及账号列表的 CPA 认证文件启停使用拨动开关，绿色向右表示启用、灰色向左表示禁用；左侧状态及筛选项显示“手动禁用”，与额度耗尽、额度受限区分。
- 主页面立即查询、立即唤醒及启用/禁用不显示确认弹窗。立即唤醒点击后读取已保存模型并提交指定账号，不夹带其他页面草稿；缺少模型或读取失败不提交。点击唤醒可能消耗一次模型额度，启用账号可能恢复已授权业务或自动任务。
- 启停仍按原始账号、真实文件名及索引核对身份，提交一次 PATCH 后通过 GET 核实真实状态。读取和提交期间锁定重复点击，外部状态已符合点击目标时只读核实；结果未知时点击原开关仅做只读核实，不重发修改。
- 自动唤醒额度提示首次确认后按当前浏览器和 CPA 地址保存，总览及规则编辑器共用；后续开关、编辑与刷新不重复要求确认。清除浏览器存储或换浏览器后会重新提示；本地存储被拒绝时在当前页面内记忆。
- 保留后台准入、任务幂等、在途锁定和未知发送防重。页面自动刷新不提交查询、唤醒或启停操作，模型唤醒页的独立手动表单与候选生成确认保持原流程。

## 升级

后台为 **0.2.0-rc.17**，原生接入层仍为 **0.2.0-rc.14**，数据库 **schema 9**、ABI 1、RPC schema 6、协议版本 1 不变。保留账号、任务、模型、提示词、已有规则及未知发送防重记录，不自动开启或关闭已有规则。

从 rc.14/rc.15/rc.16 更新且安装器核实接入层文件一致时可仅重启后台；首次切换、从 rc.13 或更早版本更新，或接入层文件变化时须显式 `--restart`。升级前保留停机或 SQLite 在线一致备份，不能只复制活动 WAL 数据库主文件。

```sh
curl -fSL -H 'Cache-Control: no-cache' https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.17
```

需要重启 CPA 时在末尾添加 `--restart`，并保留原部署的 CPA 路径、系统/用户服务参数。后续可用 `--version latest`。更新后重新打开或强制刷新网页以加载新脚本。
