# v0.2.0-rc.21 项目账号调度与赠送重置卡

增加按项目偏好、临近额度重置、会话绑定和本地并发保护的业务选号；原生桥消费后台发布的短时内存快照。配套 `cwr-codex.py` 根据目录映射为 Codex 请求添加项目标识。

增加官方赠送重置卡查询及可选到期兑换，通过 Codex App Server 账号协议接入。兑换 ID 在请求前持久保存，未知结果和重启复用同一幂等键，兑换后只读查询实际额度。所有新增自动行为默认关闭。

数据库升级至 schema 10。必须同时更新后台与原生桥并重启 CPA；升级前保留一致备份，不支持直接用旧后台打开新数据库。重置卡功能额外需要支持该协议的 Codex CLI，并注意其独立代理配置。安装、行为和边界见[完整说明](../user/account-scheduling.md)。

验证：本地 `make check`、V2 竞态检测、44 项模拟宿主集成测试、247 项面板测试及安装器测试通过。发布流程另在 amd64/arm64 构建、运行 Chromium 桌面/移动面板检查，并下载发布资产验证校验和与安装回滚。未操作真实账号或兑换真实重置卡。
