# v0.1.0-rc.27 测试版

“下一次唤醒”同时显示具体时间和随机时间范围。

## 变化

- 账号计划分为账号、具体时间、时间范围三列。已随机抽定的任务显示保存的时刻，精确到秒；没有抽定结果时显示“待抽定”和预计最早时间，不把区间起点冒充随机结果。
- 五小时、周及已分配账号的每日任务单独提供当前规则的起止范围。重置任务按原到期边界加当前已保存的延迟上下限计算；每日任务按日期、规则时区和当前每日时段计算。固定时间点标记为固定，跨日期范围保留两端日期。
- 具体时间与范围分别展示。任务等待或核对退避不会改写原定时间，也不会将范围整体移到现在。修改规则只更新范围展示，已抽定结果继续保持原值；范围表示当前规则，实际执行仍受已有额度及调度条件约束。
- 继续兼容旧快照：可读旧的预计范围，缺少范围时显示“未提供”。账号不可用等状态单独显示，未知信息不伪造。
- 仅增加计划展示数据，不改变随机抽取时机、任务持久化或发送逻辑。读取页面不抽取随机数、不查询上游、不发送模型请求。

## 升级与验证

沿用一键脚本默认热重载；已恢复配置监听的 rc.25 或 rc.26 部署不需重启。已有策略、窗口、随机截止时间和发送抑制状态保留。

回归覆盖具体时刻与范围分离、未来未抽定、基线清除后保留任务、等待核对不移动范围、每日时段与固定点、跨日期展示、旧快照，以及桌面和手机布局。发布要求 Go、竞态、原生热重载、安装器、前端、Chromium 及双架构构建通过。
