# v0.2.0-rc.29 区分账号状态与额度观测时效

修复 rc.28 调度台把“用于计算可用窗口的五分钟证据有效期”当成账号状态的问题。额度观测超过五分钟后，CPA 仍正常的账号保持“正常”，数据更新列单独提示“额度待更新”，账号详情说明具体过期字段。过期观测不再让正常账号同时显示成异常；已有禁用、暂不可用、耗尽和受限状态继续保留。

修复查询已返回、百分比正常但仍显示“观测已过期”的另一种情况：上游返回 100% 剩余额度时，可能尚未确认窗口已启动；现在显示“窗口待核实”，并解释查询额度不会启动窗口。只返回部分字段时显示“额度数据不完整”，已到重置时间和观测时钟异常也分别说明。新的顶层查询时间不会覆盖未返回字段的旧观测时间。

本次只调整展示和诊断，不放宽后台可用容量、账号筛选或模型唤醒准入，也不自动发送查询或模型请求。任务完成代表本次查询成功保存，不保证上游返回了全部窗口或确认了窗口激活。

后台和客户端版本为 **v0.2.0-rc.29**，原生接入层保持 **v0.2.0-rc.28**，数据库保持 **schema 12**。从 rc.28 更新时，安装器核实接入层文件完全一致后可仅更新并重启后台，无需重启 CPA；更新后强制刷新网页加载新页面资源。从 rc.27 或更早版本升级仍需 `--restart`，同时更新接入层，遵循 schema 12 的一致备份和回退要求。

```sh
curl -fSL https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.29
```
