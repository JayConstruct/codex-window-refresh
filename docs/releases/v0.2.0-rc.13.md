# v0.2.0-rc.13 快捷唤醒与持久响应记录

## 主界面立即唤醒

- 总览及账号表格在“立即查询”旁新增“立即唤醒”，在当前页弹出确认框，展示指定账号及已保存的默认模型；明确确认可能消耗模型额度后才提交一次。
- 快捷操作不保存唤醒页、模型页或其他页面草稿，不改变自动规则；取消确认不创建任务。未核实可用模型、禁用/暂不可用账号以及在途、未确认和未知任务继续锁定发送。
- 后台仍先只读核实额度、活动状态及绑定；按钮不会绕过账号禁用、已有活动窗口、并发占用或发送防重，也不保证一定发送模型请求。

## 响应和错误复查

- 唤醒历史新增“响应与执行记录”：持久保存最近一次模型执行的 HTTP 状态、执行阶段、响应事件与状态、上游错误代码/类型、脱敏错误信息和有限响应文本。成功、失败、部分响应后中断及关闭异常均可复查。
- 文本字段各最多 2048 字节，截断有标记。常见令牌、代理 URL、邮箱及完整提示词回显会脱敏；不保存原始响应包、请求头或完整请求提示词。摘要仍可能包含业务文本，应按账号数据同等保护数据库和备份。
- 旧任务、未进入模型发送的任务或未获得响应的执行可能没有正文；页面明确说明，不伪造响应。上游未返回可核实信息时保留已有分类与阶段，不展示任意本地原始错误字符串。
- 响应与执行结果在同一事务写入，读取和重启后保留；旧结果不能覆盖已记录结果，窗口后续只读核实完成也不覆盖原执行响应。发送中崩溃恢复为未知并记录中断，不会自动重发。
- 单任务读取补齐一致的视图版本，主界面能持续读取快捷唤醒进度；详情展开、焦点及原请求标识保护继续保留。查看记录、关闭 toast 或取消确认都不会重新调用模型。

## 升级与回退

后台为 `0.2.0-rc.13`，数据库由 schema 8 迁移至 **schema 9**，保留旧任务、规则、模型、提示词、短句池及发送防重记录。原生接入层仍为 `0.2.0-rc.8`、ABI 1/schema 6；CPA 插件列表显示 rc.8 不代表后台未更新。

**升级前另存停机或 SQLite 在线一致备份。**不能只复制活动 WAL 数据库主文件。旧后台不能直接打开 schema 9；回退必须停服务并恢复迁移前一致备份，不能仅替换二进制。安装器激活失败的临时回滚备份在成功后会清理，不能替代升级前另存的副本。

```sh
curl -fSL -H 'Cache-Control: no-cache' https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.13
```

接入层文件一致时可仅重启后台；如果提示接入层变化，确认 CPA 可以短暂中断后添加 `--restart`。首次切换、旧接入层或文件变化仍须显式重启；保留实际部署的 CPA 路径及系统/用户服务参数。后续可用 `--version latest` 更新。

升级不自动开启或关闭既有规则，安装验收不调用真实账号模型；已明确开启的自动规则继续独立执行。更新后强制刷新网页加载新资源。

## 验证与边界

覆盖 183 项 V2 前端检查、123 项安装脚本检查、Go 测试/竞态检查/vet、32 项原生桥接检查、旧面板检查及桌面/手机 Chromium 回归。新增检查包含快捷唤醒的账号绑定、确认/取消、缺少模型、失联后的防重、响应和错误脱敏、部分响应、关闭异常、事务与重放、schema 8 升级、数据库重开及未知发送恢复。

检查仅使用模拟 CPA、模型流和临时目录，不声称完成生产账号联调。本次不改变模型唤醒的安全准入与自动规则，不将模型响应完成等同于额度窗口已经启动。
