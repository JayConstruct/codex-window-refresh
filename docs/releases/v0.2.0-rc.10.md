# v0.2.0-rc.10 跨页面焦点与刷新交互修复

- 账号表格、查询历史、唤醒历史及候选短句按账号或任务标识复用控件，不再因轮询重建整块交互节点。账号状态、额度、任务进度及按钮行为继续实时更新，同一账号或任务的焦点保持不变；筛选排除或任务消失时正常移除旧节点。
- 查询历史保留已展开的逐账号详情及摘要焦点，即使任务计数或等待状态更新也不会自动收起。候选复选框在勾选、轮询和再次渲染后保留节点及选择，继续支持空格键切换；不会自动加入短句池、保存配置或重新生成。
- 未变化的模型配置读取不关闭短句池清空确认；未变化的唤醒规则读取不取消已勾选的消费确认。编辑、实际版本或实例变化、显式重新读取及保存后的必要确认失效保护继续生效，不保留过期的执行授权。
- 读取历史唤醒任务不再禁用无关的手动账号输入，读取期间仍禁止并发提交；在途、结果未知和未确认操作仍保持发送保护，不允许借此绕过防重。
- 账号后台读取不再反复禁用分页；显式翻页、刷新和同步仍使用必要锁定。新页面请求可淘汰旧轮询，旧响应或版本冲突不能回退新游标、覆盖新页面或提前解除新读取的锁定。
- 相同状态文本不重复写入，减少无变化刷新对界面及辅助阅读的干扰。保留自动更新、认证失效停用、草稿隔离、版本冲突及未知写入核实行为。

## 升级

后台为 `0.2.0-rc.10`，数据库仍为 schema 8，原生接入层仍为 `0.2.0-rc.8`、ABI 1/schema 6。组件版本不同属于正常情况；保留已有查询和唤醒规则、模型、提示词、短句池及任务防重记录，不自动开启或关闭已有规则。

升级前保留一致备份，推荐使用兼容旧接入层的显式重启命令（CPA 会短暂中断服务）：

```sh
curl -fSL https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.10 --restart
```

从 rc.9 更新且安装器确认接入层文件完全一致时可省略 `--restart`，只重启后台；首次切换、旧接入层或文件变化仍须显式重启。用户级服务继续支持 `--user-service --user 用户名 --service 服务名`。V2 一键入口不变，默认选择最新完整发布的 V2；旧 `install.sh` 仍更新 V1。

更新后强制刷新网页以获取新脚本。只读取页面、模型目录或历史不会提交模型请求；已明确开启的自动查询及自动唤醒继续按保存的规则独立运行。

## 验证与边界

回归覆盖 166 项 V2 前端检查、完整 Go 测试、竞态检查及 vet、32 项原生桥接测试、116 项安装脚本检查、旧面板检查和桌面/移动端 Chromium。真实浏览器验证查询输入及选区保持、候选复选框焦点与空格键、历史详情展开和摘要焦点、账号按钮在额度变化后的复用；纯测试覆盖旧分页响应失效、必要提交锁定和确认状态保护。

测试使用模拟 CPA、模型流及临时安装目录，未调用真实账号模型，不声称完成生产账号联调。此版本修复界面交互，不改变额度统计、模型请求格式、账号准入和后台调度规则。
