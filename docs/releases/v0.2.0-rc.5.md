# v0.2.0-rc.5 新版网页与持久额度查询调度

- 重做浅色青绿网页、侧栏与运行总览，展示运行状态、账号数量、可用容量及异常信息，移除近期活跃用户数展示。网页默认自动更新；分页、全池筛选、任务历史与 CPA 同步连接实际后台。
- 手动单账号查询立即执行；手动批量查询按账号分配随机延迟，已抽定的执行时间持久化，重启不重新抽取。同账号查询合并，单账号立即查询不必等待旧批次延迟。
- 新增独立后台的定期、五小时到期和周额度到期查询，关闭网页后仍运行。使用实际额度窗口证据安排查询，失败退避，限制每轮扫描和待执行任务数量；共享批次按账号结果推进调度。
- 新增查询设置接口及网页编辑器：随机延迟范围、查询间隔、时区和自动查询排除时段，支持变更预览、明确保存、草稿保留及并发版本冲突处理。账号和任务显示查询来源、等待原因与倒计时。
- 查询额度仅调用额度接口，不发送模型请求。自动查询默认关闭；模型唤醒、实时唤醒规则及短句生成仍未实现，不以占位控件宣称可用。
- 增加额度调度、数据库迁移、重启恢复、认证与设置冲突、原生接入和桌面/移动端浏览器回归。模拟宿主与固定数据测试不代表真实 CPA 账号已验收。
- 本地使用官方 CPA v8.0.32 空账号隔离实例，验证实际插件注册、网页资源、管理认证、新增设置路由、设置冲突及仅后台重启后的持久恢复；未导入真实账号，也未执行上游额度查询或模型请求。真实账号及 systemd 部署仍待验收。

## 升级注意

本版接入层新增 `settings` 管理路由，须使用 v2 安装器并显式添加 `--restart`，更新接入层后重启 CPA。保留现有 v2 任务及数据；首次从 v1 切换仍在验收成功后清理 v1 遗留数据。

数据库升级到 schema 4。旧后台不能直接打开新库；安装激活失败由安装器使用一致备份恢复。成功安装后会清理临时恢复副本，手动降级前须另行保留停机或 SQLite 在线一致备份，不能只替换旧二进制。

```sh
curl -fSL https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.5 --restart
```
