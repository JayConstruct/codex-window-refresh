# v0.2.0-rc.24 账号调度与重置卡界面优化

业务调度与重置卡规则改为独立设置卡，高级参数默认折叠，项目账号输入框随容器宽度展开，移除默认表单边框。桌面和手机均可直接访问记录区，两组设置仍通过一次“保存并应用全部设置”提交。

保存前检查数值范围、兑换提前量与关注时间的关系及重复项目、账号。后台明确拒绝参数时保留草稿，修正后可直接重试；配置冲突及保存结果未确认时提供只读核实，保留后续编辑。轮询不自动解除未确认保存的限制，断线禁用编辑和保存，旧连接的迟到响应不能覆盖重连后的草稿。成功保存使用后台回执确认，避免后续读取失败将已成功的保存误报为未确认。

“到期前自动使用”依赖详情查询。手动关闭详情查询会同时关闭自动使用草稿；旧配置中仅自动使用开启时说明当前不会运行，读取页面不修改后台设置。

记录区提供卡片概况与兑换记录、搜索、需关注筛选及每页十条浏览。展示数量与详情各自的真实观测时间、卡片及兑换标识、最近更新时间和中文兑换结果，缺少时间保持未知，数量摘要不会伪装成新的详情观测。轮询保留仍存在的卡片详情展开状态和焦点，账号显示遵循全局打码及别称偏好。记录来自已观测账号和后台最近最多一百条兑换记录，不作为永久审计历史；刷新、搜索、翻页及保存核实不查询上游、不兑换卡片。

后台为 **rc.24**，原生接入层继续使用 **rc.23**，数据库保持 **schema 10**。从 rc.23 更新且安装器确认接入层文件完全一致时，可省略 `--restart`，仅重启后台；首次切换、从 rc.22 或更早接入层升级、或接入层文件变化时仍须显式 `--restart`。更新后强制刷新网页。已有规则、额度及发送防重记录保留，仅重启后台不清空原生桥内存中的有效会话绑定。

验证覆盖新增保存与断线回归、数量与详情时间隔离、列表搜索分页、中文结果、隐私显示及展开焦点保留。真实 Chromium 覆盖 320、390、768、1586 像素布局，以及完整面板和自动刷新回归；发布流水线分别在 amd64/arm64 构建、测试，并下载公开安装包验证校验和、安装更新及回滚。测试使用模拟宿主及临时数据，未操作真实账号或重置卡。

使用说明见[面板说明](../backend-v2-panel.md#账号调度与重置卡)，更新方式见[V2 安装与更新](../backend-v2-install.md)。
