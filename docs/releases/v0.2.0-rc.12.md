# v0.2.0-rc.12 查询同步账号状态与任务错误详情

## 查询时同步账号状态

- 手动单账号、批量和自动额度查询共用状态更新链路：复用 CPA 本地身份核实读取到的正常、禁用或暂不可用状态，随实际查询结果提交，不必等待下一轮 30 秒同步；原定时同步仍保留。
- 额度查询失败时，已独立核实且绑定有效的宿主状态也可更新。缺少查询令牌仍可保留已核实的宿主状态；查询成功不会擅自解除禁用，认证失败、403 或网络异常不被推断为额度耗尽。
- 额度耗尽和受限继续依据有效额度证据；失败不清空最后一次有效额度。宿主状态更新不写 CPA 账号开关，也不增加模型请求。
- 状态证据按账号、凭据绑定与观测时间校验，和查询结果在同一事务提交。旧查询、重复结果、已删除账号、变更绑定或较新的定时同步不会被过期状态覆盖。

## 查看任务错误详情

- 查询历史支持读取逐账号结果及错误详情，显示任务 ID、具体账号、阶段、脱敏错误代码、记录时间、失败环节和排查建议；运行总览中异常任务也可进入查看。
- 逐账号错误单独列出，不受前 20 条普通结果预览限制；超过 20 个错误可继续展开查看，避免批量任务后部的失败账号不可见。
- 唤醒历史及当前候选生成失败或未知结果保留可展开详情，关闭 toast 后仍可查阅。详情采用纯文本，不回显凭据、代理密钥、模型提示词或上游原始错误响应；未知错误使用通用分类。
- 查看详情仅执行读取，不创建查询或模型任务；轮询保留展开状态和键盘焦点。结果未知仍只允许核实原任务，不因关闭提示或展开详情解除发送防重。

## 升级

后台版本为 `0.2.0-rc.12`，数据库仍为 schema 8，原生接入层仍为 `0.2.0-rc.8`、ABI 1/schema 6。CPA 插件列表仍可能显示 rc.8；以安装器核实的实际后台版本或网页诊断中的后台版本判断更新结果。

升级前另存停机或 SQLite 在线一致备份。更新到本版：

```sh
curl -fSL -H 'Cache-Control: no-cache' https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.12
```

只有接入层文件一致时可不重启 CPA，仅重启独立后台；提示接入层变化时，确认允许 CPA 短暂中断后添加 `--restart`。首次切换、旧接入层或文件变化仍须显式重启。保留实际部署的 CPA 路径及系统/用户服务参数；后续可用 `--version latest` 更新。

升级保留现有 V2 查询/唤醒规则、模型、提示词、短句池及任务防重记录，不自动开启或关闭既有规则。安装验收不调用真实账号模型；已明确开启的自动规则继续独立执行。更新后强制刷新网页加载新资源。

## 验证与边界

覆盖 179 项 V2 前端检查、123 项安装脚本检查、Go 测试/竞态检查/vet、32 项原生桥接检查、旧面板检查及桌面/移动端 Chromium 回归。

新增检查覆盖查询成功与失败的状态提交、查询期间禁用/恢复、缺少令牌、旧状态与新绑定隔离、结果重放、失败保留有效额度，以及跨账号错误列表、继续展开、未知错误脱敏、关闭 toast 后查阅、只读行为、焦点和手机布局。

所有检查使用模拟 CPA、模型流及临时目录，不声称完成生产账号联调。不改变模型请求格式、额度解析、安全准入或自动唤醒规则；状态更新也不会把未知额度推断为可用窗口。
