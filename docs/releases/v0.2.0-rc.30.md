# v0.2.0-rc.30 简化账号更新时间

总览账号表格的数据更新列只显示“刚刚”“几分钟前”等相对时间，移除“额度待更新”和观测时间异常的附加提示。账号详情继续说明额度观测时效及窗口核实原因；后台容量、查询、唤醒及分流规则保持不变。

后台和客户端版本为 **v0.2.0-rc.30**，接入层保持 **v0.2.0-rc.28**，数据库保持 **schema 12**。从 rc.28 或 rc.29 更新时，安装器确认接入层文件完全一致后可省略 `--restart`，仅更新并重启后台；完成后强制刷新网页。从 rc.27 或更早版本升级仍须显式 `--restart` 并遵循 schema 12 的备份与回退要求。

前端回归及本地 Chromium 验证通过，覆盖旧观测只显示时间、查询后更新时间、详情说明和正常账号状态；验证不使用真实账号或上游模型。发布流程继续执行双架构构建、完整测试和公开安装包回读验证。
