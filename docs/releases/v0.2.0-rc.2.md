# v0.2.0-rc.2 部署清理旧版

部署成功后清除 v1 遗留策略、状态、环境文件、安装记录及备份，删除未选中的旧插件动态库和旧后台版本目录。后续更新继续保留 v2 数据库、任务和幂等记录。

- 清理只在新后台、接入实例和目标 CPA PID 验证成功后执行；激活失败仍可用临时副本恢复，成功后删除恢复副本。
- 去掉 CPA 插件包装中的 v1 配置字段和旧服务环境 drop-in。清理旧服务环境时需要显式 `--restart`。
- 清理校验保护 CPA 主程序、主配置、账号目录、当前 v2 数据与其他插件；符号链接或重叠的危险路径拒绝删除。
- 后台与接入层独立记录版本，安装时按实际接入层版本命名，保留当前选中的接入层文件。

首次或从 v1/rc.1 清理切换建议执行最新 `scripts/install-v2.sh --restart`。本版仍是只读预发布，不执行模型或自动唤醒；测试使用模拟 CPA，真实宿主仍需实机验收。
