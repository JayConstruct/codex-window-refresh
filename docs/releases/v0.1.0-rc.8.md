# v0.1.0-rc.8 测试版

修复页面接口能力不更新的问题，并为额度查询未就绪提供具体配置诊断。

## 本次变化

- 接口能力随页面快照每 5 秒更新。插件启动初期尚未就绪的状态，不再一直阻止手动查询。
- “诊断与高级”新增“额度查询连接”，明确提示缺少后台管理地址、缺少环境变量名、CPA 进程未读取到管理密钥或管理地址无效，并给出修复方向。
- 额度适配器状态显示“已就绪 / 未就绪”，避免误解为宿主不支持额度查询。
- `GET /capabilities` 增加 `quota_bridge` 配置诊断，保留原能力字段。诊断不联系上游，不返回管理密钥值或地址。

## 使用和升级

升级至本版后重启 CPA 并刷新页面。若仍未就绪，查看“诊断与高级 → 额度查询连接”，检查 CPA 主配置中的 `plugins.configs.codex-window-refresh.management_url` 和 `management_key_env`。

systemd 服务必须通过 EnvironmentFile 等服务配置向 CPA 进程传入现有管理密钥，并在修改后重启；浏览器登录或终端临时 export 不会补充已运行服务的环境。已具备配置只表示可发起查询，不代表上游连通性或认证已验证。

安装脚本指定 `--version v0.1.0-rc.8`，沿用原 CPA 路径、服务和用户参数。保留已有策略、密钥文件和窗口状态；提供 Linux amd64、arm64 安装包及 SHA256SUMS。

## 验证与边界

通过本地配置诊断与不泄露密钥的接口测试，以及 Chromium 中启动时未就绪、后台就绪后自动恢复按钮的验证。继续执行 Go 检查、竞态检测、原生插件加载和前端回归测试。

本版不修改后台额度接口或模型唤醒规则。仍要求 CPA ABI 1 / RPC schema 6；尚未在真实 CPA 宿主或生产账号上联调。
