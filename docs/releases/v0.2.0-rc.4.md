# v0.2.0-rc.4 CPA 注册与页面入口修复

- 补齐原生接入层必需的 Author 和 GitHubRepository。rc.3 缺失这两个字段，CPA 会拒绝注册，因此网页显示插件未注册，侧栏没有页面入口。
- 安装验收增加经过 CPA 公开资源路由的健康检查：必须返回与私有 socket 相同的后台版本和实例 ID。接入层已启动但宿主尚未接受注册时，不再报告安装成功；激活失败回滚配置与 v2 数据库。
- 新增 `/v0/resource/plugins/codex-window-refresh/healthz`，仅公开就绪状态、后台版本、只读标记和实例 ID。通过 CPA 配置推断监听地址与 TLS，必要时用 `--cpa-url` 指定可验证证书的地址；不发送管理密钥、不查询账号或调用模型。
- 回归覆盖 CPA 必需元数据和侧栏资源菜单，重现“socket 连通但插件未注册”，验证安装拒绝该状态以及页面和健康路由恢复。测试使用固定 CPA 注册规则的假宿主，不声称真实 CPA 实机验收。

本次接入层变化，需要 `--restart` 重启 CPA。保留现有 v2 数据；成功后继续清除 v1 遗留数据和旧版本。
