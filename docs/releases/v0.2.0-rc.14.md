# v0.2.0-rc.14 统一任务记录与交互完善

## 任务记录

- 重做任务页，沿用运行总览的浅色与青绿色风格：四项统计、状态标签、搜索筛选、真实分页、任务列表及只读详情。适配 2560×1600、1280×900 和手机布局。
- 统一展示后台持久保存的手动、自动额度查询与模型唤醒记录，包括定期及额度到期查询、唤醒前后只读核实、五小时/周重置唤醒及每日容量准备；不以当前浏览器会话或最近二十条冒充全部历史。
- 支持按类型、来源、实际触发规则、创建日期和全部执行状态筛选，包括已跳过、已取消和结果未知。摘要和状态计数遵循其他筛选但忽略状态筛选，今日按浏览器本地日界计算。
- 批量任务显示实际账号数量、执行及排队进度；尚有排队项时优先展示最早待执行计划。查询有真实开始与终止证据时显示耗时，未开始任务及缺少可靠起止证据的模型执行不编造耗时。

## 详情与安全

- 详情保留逐账号结果、错误分类和已有有限脱敏模型响应，未知结果警告常驻滚动区域外。查看、刷新和只读核实均不创建任务，不查询上游额度或重发模型请求。
- 列表与详情按同一后台实例的视图修订号判断新旧，旧详情不能回退新状态；响应区块增减不移动正在阅读的节点，保留展开和焦点。复制任务 ID 在无安全剪贴板的 HTTP 部署提供只读选择框，不向网络发送内容。
- 手机显式打开详情时定位并聚焦标题，关闭后尽可能返回原按钮；自动轮询不跳转、不抢焦点。搜索只按公开错误分类和脱敏模型匹配，避免通过私有内容探测隐藏错误或模型字符串。
- 修复取消快捷唤醒后立即重开同账号时，旧浏览器关闭事件误关新确认框的问题。新确认框不继承旧消耗确认，只有重新明确确认才提交一次；未增加模型重试或放宽发送保护。

## 升级

**后台及原生接入层均为 `0.2.0-rc.14`，本次必须同时更新并显式重启 CPA。**接入层新增只读管理路由 `task-history` 及其筛选参数；旧 rc.8 接入层仅替换后台不能提供统一记录。ABI 1、RPC schema 6 和协议版本 1 保持不变。

数据库仍为 **schema 9**，从 rc.13 升级不增加迁移；保留现有任务、模型、提示词、规则及发送防重记录。从更早版本升级仍受既有迁移与降级限制。升级前另存停机或 SQLite 在线一致备份，不能只复制活动 WAL 数据库主文件；安装成功会清理临时回滚备份，不能替代自行留存的副本。

确认 CPA 可以短暂重启后执行，并保留实际部署所需的 CPA 路径、系统/用户服务参数：

```sh
curl -fSL -H 'Cache-Control: no-cache' https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install-v2.sh -o /tmp/cwr-v2-install.sh
sudo bash /tmp/cwr-v2-install.sh --version v0.2.0-rc.14 --restart
```

以后可用 `--version latest`。升级后强制刷新网页。不会自动开启或关闭已有规则；用户明确开启的自动规则继续独立运行。本次未修改模型发送准入，不将模型完成等同于额度窗口启动。
