# v0.1.0-rc.19 测试版

新增 CPA 本地账号状态刷新，短句池生成支持反重力账号与模型，并精简账号卡片提示。

## 本次变化

- 页面右上角增加“从 CPA 刷新”，在各标签页均可使用，立即同步 CPA 本地账号清单、禁用及可用状态。使用独立的认证接口，不连接上游、不查询额度、不发送模型请求，也不通知调度器重新检查规则。
- 刷新保留未保存的配置及 JSON 草稿、已有额度的原始观测时间；账号绑定改变时清除旧绑定的额度证据。读取或持久化失败时不发布成功，迟到的旧页面响应不会覆盖新状态。
- 移除禁用或暂不可用账号卡片内的长篇状态检查提示，保留简短状态标签，减少对卡片布局的影响。
- 一并发布工作区已有的账号唤醒计划优化：“计划与历史”使用紧凑的账号/下一次唤醒两列表格，按时间排序；每账号摘要始终计算，不依赖完整计划开关，也不受详细计划 256 条上限影响。未知、暂停或不可用账号显示原因，不推算不存在的唤醒时间。
- “用模型批量生成候选短句”支持选择 CPA 中的反重力账号，显式填写该账号在 CPA 中可用的模型名。请求固定到所选账号和反重力提供商，使用宿主协议转换与模型流回调，无需另填密钥，不继承 Codex 默认模型。
- 反重力账号使用独立的生成目录，不进入 Codex 五小时/周额度、账号容量或自动唤醒池，不调用 Codex 额度查询。仍核对账号可用状态、身份绑定、已知前台活动和发送间隔，并在模型调用前持久化送达记录。
- 生成沿用候选校验、预览、应用到目标短句池草稿和单独保存的流程。失败、超时或送达不确定不会自动重试；重启保留未知送达记录。执行历史包含反重力提供商标识。

## 安装或升级

已有 CPA 的 Debian 12/13 服务器可指定版本升级：

```sh
curl -fSL https://raw.githubusercontent.com/JayConstruct/codex-window-refresh/main/scripts/install.sh -o /tmp/codex-window-refresh-install.sh && sudo bash /tmp/codex-window-refresh-install.sh --version v0.1.0-rc.19
```

升级保留已有策略、模型、窗口和发送抑制状态，无需清空状态。安装器默认重启已核实的 CPA systemd 服务；使用 `--no-restart` 可稍后手动重启。Docker 按安装指南替换插件。替换插件并重启 CPA 后刷新管理面板。

使用反重力生成时，先点击“从 CPA 刷新”，在“模型唤醒 → 用模型批量生成候选短句”选择带“反重力”前缀的账号，填写该账号可用的模型名，确认生成后预览并应用到目标池，再保存配置。生成会消耗所选账号额度。

新增状态字段写入后，回退旧版本需停服务并恢复升级前对应备份。

## 验证与边界

回归覆盖 CPA 账号禁用/恢复、增删和绑定变更，刷新失败、草稿保留、重复点击及旧响应隔离；覆盖反重力账号/提供商/模型固定、协议文本解析、账号禁用与身份变更拦截、前台活动、持久化失败、未知送达、重启抑制及候选预览应用。

发布流程要求 Linux amd64、arm64 各自通过完整 Go 测试、竞态检测、vet、原生 ABI 加载、安装器及前端检查，并通过 Chromium 浏览器回归后才发布两种安装包与 SHA256SUMS。

仍要求 CPA ABI 1 / RPC schema 6；自动化验证使用模拟宿主，尚未连接真实 CPA 宿主或反重力生产账号联调。模型必须已在目标 CPA 中可用且可路由。已有自动查询和唤醒继续按独立策略运行，本地刷新不修改这些策略。
